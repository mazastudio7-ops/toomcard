# 스타 (자랑 피드) 기획

> 한 줄: **내가 만든 카드로 나를 알리고, 모두가 좋아요로 응원하는 곳.**
> "이젠 누구나 스타" — 예전 브랜드 이젠스타의 정신을 툼카드 안에서 잇는다.

## 1. 정해진 것

| 항목 | 결정 |
|---|---|
| 위치 | 홈 상단 탭 **갤러리 \| 스타** (툼카드 안의 공간으로 시작, 커지면 분리 가능) |
| 좋아요 | 로그인 없이. 한 기기에서 카드당 한 번. 싫어요·댓글 없음 |
| 카드 클릭 | 그 사람의 카드 페이지(`/slug`)로. 거기서 링크로 이동 |
| 첫 버전 | 자랑하기 켜기 · 스타 피드 · 좋아요 · **링크 클릭 수** · **주간 스타** · **분야 태그** · 신고 |
| 나중 | 홍보 부스트(유료), 팔로우, 알림 |

## 2. 사용자 흐름

1. **만들기 → 발행**: 발행 화면에 `스타에 올리기` 스위치(기본 꺼짐)와 분야 태그 하나 고르기.
2. **스타 피드**: 홈 `스타` 탭. 카드 앞면 + 이름 + 한 줄 소개 + ♥ 수 + 태그.
   - 정렬: `인기`(최근 7일 좋아요) / `새로운`
   - 태그 칩: 전체 · 학생 · 크리에이터 · 사업 · 음악 · 디자인 · 기타
3. **좋아요**: 피드 카드와 카드 페이지 하단에 ♥. 누르면 금색으로 차오르는 짧은 모션.
4. **카드 페이지**: 받은 사람·피드에서 온 사람 모두 ♥ 가능. 링크를 누르면 클릭 수가 쌓임.
5. **대시보드**: `이번 주 조회` · `♥ 좋아요` · `링크 클릭` 세 숫자. "내 카드 키우기"에 다섯 번째 할 일 `스타에 올리기`.
6. **주간 스타**: 지난 7일 좋아요 상위 카드 1~3장을 홈 첫 화면(히어로 아래)에 "이번 주 스타"로 소개.

## 3. 화면에 보이는 것 (카드 한 장)

- 카드 앞면 이미지(사진·플레이트·단색) — 대시보드와 같은 떠 있는 카드
- 이름, 한 줄 소개(role), 태그 칩
- ♥ 버튼 + 숫자
- 신고는 카드 페이지의 `더보기` 안에만 (피드를 깨끗하게)

## 4. 데이터 (Supabase)

| 무엇 | 저장 위치 | 비고 |
|---|---|---|
| 스타 공개 여부 | `pods.components_json.star = { on, tag, since }` | 본인만 수정(기존 RLS) |
| 좋아요 | 새 표 `star_likes(slug, device_id, created_at)` | `unique(slug, device_id)`, 누구나 추가, 집계만 공개 |
| 링크 클릭 | 새 표 `link_clicks(slug, kind, created_at)` | kind = instagram/youtube/web… 누구나 추가 |
| 신고 | 새 표 `star_reports(slug, reason, created_at)` | 누구나 추가, 관리자만 읽기 |
| 숨김 | `pods.components_json.star.hidden = true` | 신고 3건 이상이면 자동 숨김 → 관리자 확인 |

- `device_id`: 처음 방문 때 만든 무작위 값(localStorage). 개인정보 아님.
- 피드는 `star.on = true and not hidden` 카드만 읽는 공개 함수(또는 뷰)로 가져온다.

## 5. 규칙과 안전

- **기본 꺼짐**: 얼굴이 공개되므로 본인이 켤 때만. 끄면 즉시 피드에서 사라짐.
- **만 14세 이상**: 이미 발행 전에 확인 중. 스타 공개도 같은 확인을 따름.
- **신고**: 사유 3가지(부적절한 사진 · 사칭 · 스팸). 3건이면 자동 숨김.
- **독일(DSA)**: 신고 창구와 처리 안내 문구를 개인정보 고지에 추가.
- **조작 방지(가볍게)**: 같은 기기 중복 좋아요 차단, 1분에 30개 이상 누르면 무시.

### 5-1. 1차 검열 (AI 없이)

스타에 올린 카드는 **바로 공개되지 않고 "검토 중"** 으로 들어간다. 사람이 보고 승인해야 피드에 뜬다.

| 단계 | 하는 일 |
|---|---|
| ① 자동 거르기 (규칙) | 이름·소개·태그에 금지어 목록(욕설·성인·도박·불법 키워드, ko/en/de) → 걸리면 "검토 필요" 표시 |
| | 링크 검사: 단축 URL·성인·도박 도메인 차단 목록, `http`만 있는 링크 경고 |
| | 사진 없이 기본 플레이트만 쓴 카드, 이름 없는 카드 → 피드 대상 아님 |
| | 같은 사람이 하루 3장 넘게 올리면 보류 |
| ② 사람 승인 (관리자 화면) | `/admin/star` (= /admin-star) : 검토 대기 카드 목록 → **승인 / 거절(사유)** 버튼 두 개. 휴대폰에서도 한 손으로 |
| ③ 신뢰 사용자 | 한 번 승인된 사람이 나중에 카드를 고치면 바로 반영, 단 사진이 바뀌면 다시 검토 |
| ④ 공개 후 | 신고 3건 → 자동 숨김 → 관리자 화면 맨 위로 |

- 사용자에게는 "검토 후 하루 안에 올라가요" 안내, 승인되면 대시보드에 "스타에 올라갔어요" 표시.
- 나중에 양이 많아지면 사진 자동 검사(브라우저 안에서 도는 무료 모델)를 ①에 추가해 "검토 필요"만 사람이 보게 한다.

## 5-2. 공개 설정 (무엇을 보여 줄지)

명함으로 직접 준 사람과 스타에서 처음 본 사람은 다르다. **같은 카드, 두 가지 보기**로 나눈다.

| 항목 | 명함 링크로 받은 사람 | 스타에서 온 사람 (공개 보기) | 기본값 |
|---|---|---|---|
| 이름 · 한 줄 소개 · 사진 | 보임 | 보임 | — |
| 홍보 링크 (인스타·유튜브·웹·추가 링크) | 보임 | **고른 것만** | 전부 공개 |
| 전화번호 | 보임 | **숨김** | 비공개 |
| 이메일 | 보임 | 숨김 | 비공개 |
| 카톡 · 연락처 저장 버튼 | 보임 | 숨김 | 비공개 |

- 발행 화면 `스타에 올리기` 아래에 항목별 스위치: `전화번호 공개` · `이메일 공개` · 링크마다 `공개`.
- **명함 링크**: 대시보드의 `링크 보내기`는 비밀 키가 붙은 주소(`/slug?k=…`)를 준다 → 전부 보임.
- **공개 주소**: 키 없는 `/slug`(스타에서 연결되는 주소)는 공개 항목만 보인다.
- **진짜로 숨기려면** 전화·이메일을 카드 데이터와 분리해 저장해야 한다(지금은 카드 데이터 전체를 누구나 읽을 수 있음). → 비공개 항목은 `pods.private_json`(본인만 읽기)으로 옮기고, 키가 맞을 때만 서버가 합쳐서 보낸다. 스타를 켜지 않은 기존 카드는 지금처럼 동작.

## 6. 성공 지표

- 발행한 사람 중 `스타에 올리기`를 켠 비율
- 스타 피드 → 카드 페이지 → 링크 클릭 비율 (= 광고 도구로서의 가치)
- 스타 피드를 보고 `나도 만들기`로 넘어간 수
- 주간 재방문(대시보드를 다시 연 사람)

## 7. 열기 전에 할 일

- **빈 피드 방지**: 지인 카드 10~20장을 먼저 스타에 올려 두고 공개.
- 첫 주 주간 스타는 직접 골라도 됨.

## 8. 작업 순서

1. Supabase 표 3개 + 공개 피드 함수 + RLS + `private_json`(비공개 항목 분리)
2. 발행 화면: 스타 스위치 + 태그 + 공개 설정(전화·이메일·링크별)
3. 명함 링크(키) / 공개 보기 나누기 — 카드 페이지와 render API
4. 1차 검열: 금지어·링크 규칙 + `/admin/star` 승인 화면
5. 홈 `스타` 탭: 피드, 정렬, 태그, ♥
6. 카드 페이지: ♥ + 링크 클릭 기록 + 신고
7. 대시보드: 세 숫자 + 다섯 번째 할 일 + 검토 상태
8. 홈: 이번 주 스타
9. 개인정보 고지 문구(ko/en/de)

예상: 사흘(1~7), 반나절(8~9). 공개 설정(1·3)이 서버 쪽에서 가장 손이 많이 간다.
