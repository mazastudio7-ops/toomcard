# TOOMCARD 개선 로드맵

작성: 2026-10-22

**목표 한 줄:** 지인 10명이 자기 명함 링크를 자랑스럽게 뿌릴 수 있는 상태. 한국어·영어·독일어.

**원칙**
1. 빼는 게 먼저, 더하는 건 나중
2. 원본 하나, 언어는 사전으로 (파일 복사 금지)
3. 받는 사람 화면(뷰어)이 1순위, 만드는 사람 화면(메이커)이 2순위

**브랜드:** 모든 나라에서 TOOMCARD 하나. 독일 화면에는 "Digitale 3D-Visitenkarte" 설명어와
"TOOM = To Day, To Tomorrow"를 항상 붙인다. TOOMUS는 기업용으로 아껴 둔다.
("toom"은 독일 REWE 그룹 상표이고 "toom Card"는 그 회사 상품명이므로, "Toom ... Card"처럼 띄어 쓴 이름은 쓰지 않는다.)
